# File Creator - консольная утилита для создания json-списка с контрольными суммами.

## Возможности
- Добавление одного файла (вычисление CRC32).
- Добавление всех файлов из директории (нерекурсивно или рекурсивно с флагом `-r`).
- Удаление файла из списка.
- Задание пути для сохранения JSON-списка (по умолчанию `file_list.json` в папке с утилитой).
- Сохранение списка в JSON-файл.

## Установка и запуск

1. **Склонируйте репозиторий** (или скачайте файл `main.py`):
   ```bash
   git clone https://github.com/Rometei/files_list_utility.git
   cd files_list_utility
2. Запустите утилиту
   ```bash
   python main.py
4. Укажите путь для сохранения по умолчанию (опционально):
   ```bash
   python main.py --output /путь/к/списку.json
6. После запуска появится приглашение >. Вводите команды (все команды начинаются со слеша /).

# File Creator - консольная утилита для создания json-списка с контрольными суммами.

## Возможности
- Добавление одного файла (вычисление CRC32).
- Добавление всех файлов из директории (нерекурсивно или рекурсивно с флагом `-r`).
- Удаление файла из списка.
- Задание пути для сохранения JSON-списка (по умолчанию `file_list.json` в папке с утилитой).
- Сохранение списка в JSON-файл.

## Установка и запуск

1. **Склонируйте репозиторий** (или скачайте файл `file_creator.py`):
   ```bash
   git clone https://github.com/ваш-username/название-репозитория.git
   cd название-репозитория
2. Запустите утилиту
   python file_creator.py
3. Укажите путь для сохранения по умолчанию (опционально):
   python file_creator.py --output /путь/к/списку.json
4. После запуска появится приглашение >. Вводите команды (все команды начинаются со слеша /).
